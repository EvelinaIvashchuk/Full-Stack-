# Лабораторна робота №13. FastAPI-додаток з Ormar-моделлю та PostgreSQL у Docker

Виконала: Іващук Евеліна, група 444Б

## Файли проекту

| Файл | Призначення |
|---|---|
| `main.py` | FastAPI-додаток: підключення до бази даних, модель `Book`, ендпоїнти |
| `Dockerfile` | опис образу контейнера з додатком |
| `docker-compose.yml` | запуск двох контейнерів: PostgreSQL і FastAPI-додатку |

## Запуск

1. Запустіть Docker Desktop і дочекайтеся, поки він повністю завантажиться.
2. Відкрийте термінал у папці `Lab13` і виконайте:
   ```
   docker compose up --build
   ```
3. Відкрийте у браузері http://localhost:8000/docs — це сторінка Swagger для тестування API.

Перший запуск триває кілька хвилин: Docker завантажує образи Python і PostgreSQL та встановлює бібліотеки.

## Ендпоїнти

- `GET /books/` — список усіх книг;
- `GET /books/{book_id}` — книга за номером; якщо такої немає, повертається помилка 404.

## Зупинка

У терміналі натисніть `Ctrl+C`, потім виконайте:

```
docker compose down
```

Дані бази зберігаються в томі `pgdata`. Щоб видалити і їх, виконайте `docker compose down -v`.

## Про порт бази даних

На цьому комп'ютері вже працює локальний PostgreSQL, який займає порт 5432. Тому у файлі `docker-compose.yml` для контейнера з базою даних указано зовнішній порт 5433 (`- "5433:5432"`).
Адресу `DATABASE_URL` змінювати не потрібно: усередині мережі Docker база даних доступна на порту 5432.
