# Лабораторна робота №10. Сайт гурту «Океан Ельзи» на Flask

Виконала: Іващук Евеліна, група 444Б

## Що вміє сайт

- сторінки «Головна», «Про проект», «Історія гурту» і окрема сторінка кожного альбому;
- реєстрація, вхід і вихід користувачів;
- додавання, редагування і видалення альбомів (лише після входу).

## Структура проекту

| Файл | Призначення |
|---|---|
| `app.py` | програма: маршрути, робота з базою даних, авторизація |
| `templates/` | HTML-шаблони сторінок (Jinja2) |
| `static/style.css` | оформлення сайту |
| `requirements.txt` | бібліотеки, потрібні для роботи сайту |
| `Procfile` | команда запуску сайту на Heroku |
| `band.db` | база даних SQLite, створюється автоматично під час першого запуску |

## Запуск на своєму комп'ютері

У папці `Lab10` вже створено віртуальне середовище `.venv` з Flask. Відкрийте термінал у цій папці та виконайте:

```
.venv\Scripts\python.exe app.py
```

Після цього відкрийте у браузері адресу http://127.0.0.1:5000

Щоб керувати альбомами, зареєструйтеся на сторінці **Register** і увійдіть на сторінці **Log in**.

Якщо папки `.venv` немає (наприклад, проект скопійовано на інший комп'ютер), створіть її заново:

```
py -m venv .venv
.venv\Scripts\python.exe -m pip install Flask
```

## Розгортання на Heroku

Потрібні обліковий запис Heroku, встановлені Git і Heroku CLI. Heroku не має безкоштовного тарифу, тому для створення застосунку потрібно додати платіжну картку.

1. Увійти в Heroku: `heroku login`
2. У папці `Lab10` створити репозиторій і зберегти файли:
   ```
   git init
   git add .
   git commit -m "Flask site of the band"
   ```
3. Створити застосунок: `heroku create`
4. Задати секретний ключ для сесій (будь-який довгий випадковий рядок):
   ```
   heroku config:set SECRET_KEY=your-long-random-string
   ```
5. Надіслати код на Heroku: `git push heroku main` (або `git push heroku master`, якщо гілка називається `master`)
6. Відкрити сайт: `heroku open`

Heroku читає `requirements.txt`, встановлює Flask і Gunicorn та запускає сайт командою з файла `Procfile`.

**Зауваження.** Файлова система Heroku тимчасова: файл `band.db` створюється заново після кожного перезапуску застосунку, тому зареєстровані користувачі й додані альбоми не зберігаються надовго. Для навчальної роботи цього достатньо; для постійного зберігання даних потрібна окрема база даних, наприклад Heroku Postgres.
