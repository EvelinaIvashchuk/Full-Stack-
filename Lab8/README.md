# Лабораторна робота №8. Класи. Частина 3

Виконала: Іващук Евеліна, група 444Б

## Файли

| Файл | Призначення |
|---|---|
| `task_01.py` | класи `Alphabet` і `EngAlphabet` |
| `task_02.py` | класи `Human`, `House`, `SmallHouse` |
| `task_03.py` | класи `Apple`, `AppleTree`, `Gardener` |
| `kmr.py` | класи `KmrCsv`, `Statistic`, `Plots`, `KmrWork` (завдання 4) |
| `task_04.py` | тести до модуля `kmr.py` |
| `kmr1.csv`, `kmr2.csv` | файли з оцінками за дві КМР, надані викладачем |
| `results/` | графіки та файл порівняння, які створює `task_04.py` |

## Запуск

Завдання 1–3 не потребують додаткових бібліотек:

```
py task_01.py
```

Для завдання 4 потрібна бібліотека matplotlib. Вона встановлена у віртуальному середовищі `.venv`:

```
.venv\Scripts\python.exe task_04.py
```

Наприкінці програма показує вікно з графіком порівняння двох КМР. Щоб програма завершилася, закрийте це вікно.

Якщо папки `.venv` немає, створіть її:

```
py -m venv .venv
.venv\Scripts\python.exe -m pip install matplotlib
```
