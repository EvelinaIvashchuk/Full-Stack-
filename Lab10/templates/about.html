About the project

This site is an educational project created for laboratory work No. 10 "Working with Flask" of the course "Full-Stack development of intelligent applications".

What the site can do

  • shows the pages "Home", "About the project", "Band history" and a page for every album;
  • lets visitors register and log in;
  • lets logged-in users add, edit and delete album pages.

Technologies

  • Python and the Flask web framework;
  • Jinja2 templates for HTML pages;
  • SQLite database for albums and users;
  • HTML and CSS without additional front-end libraries;
  • Gunicorn web server for deployment on Heroku.
