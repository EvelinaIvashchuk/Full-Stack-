# Лабораторна робота №11. Telegram-бот для тестування знань Python

Виконала: Іващук Евеліна, група 444Б

## Що вміє бот

- після команди `/start` по черзі задає 10 питань про Python з чотирма варіантами відповіді (кнопки);
- питання і варіанти відповідей щоразу йдуть у випадковому порядку;
- після кожної відповіді одразу показує, правильна вона чи ні;
- у кінці показує кількість балів, дату і тривалість тесту та звіт по кожному питанню.

## Файли проекту

| Файл | Призначення |
|---|---|
| `bot.py` | програма бота |
| `questions.py` | тестові питання |
| `test_bot.py` | тести логіки бота (запускаються без Telegram) |
| `requirements.txt` | бібліотека, потрібна для роботи бота |
| `Procfile` | команда запуску бота на Heroku |

## Як отримати токен бота

1. У Telegram відкрийте бота **@BotFather**.
2. Надішліть команду `/newbot`, введіть назву бота та його ім'я користувача (має закінчуватися на `bot`).
3. BotFather надішле токен — довгий рядок виду `1234567890:AA...`. Нікому його не показуйте і не вставляйте у звіт.

## Запуск на своєму комп'ютері

1. У папці `Lab11` створіть файл `token.txt` і вставте в нього токен (один рядок).
2. Відкрийте термінал у цій папці та виконайте:
   ```
   .venv\Scripts\python.exe bot.py
   ```
3. У Telegram знайдіть свого бота і надішліть йому `/start`.

Зупинити бота: `Ctrl+C` у терміналі.

Якщо папки `.venv` немає, створіть її заново:

```
py -m venv .venv
.venv\Scripts\python.exe -m pip install pyTelegramBotAPI
```

## Перевірка без Telegram

```
.venv\Scripts\python.exe test_bot.py
```

## Розгортання на Heroku

Потрібні обліковий запис Heroku, встановлені Git і Heroku CLI. Heroku не має безкоштовного тарифу.

1. `heroku login`
2. У папці `Lab11`:
   ```
   git init
   git add .
   git commit -m "Telegram quiz bot"
   ```
   Файл `token.txt` у репозиторій не потрапляє (він указаний у `.gitignore`).
3. `heroku create`
4. Передати токен боту через змінну середовища:
   ```
   heroku config:set BOT_TOKEN=your-token-from-BotFather
   ```
5. `git push heroku main` (або `git push heroku master`)
6. Запустити процес бота: `heroku ps:scale worker=1`
7. Переглянути журнал роботи: `heroku logs --tail`

Бот не є вебсайтом, тому в `Procfile` використано процес типу `worker`, а не `web`.
Одночасно має працювати лише одна копія бота: перед запуском на Heroku зупиніть бота на своєму комп'ютері.
