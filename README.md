# Full-Stack розробка інтелектуальних додатків

У кожній папці – програми з коментарями і звіт `Звіт_ЛРN_Іващук_Евеліна.docx`.

`pip install -r requirements.txt` у папці роботи; лабораторна 13 запускається командою
`docker compose up --build`.
