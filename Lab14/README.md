# Лабораторна робота №14. FastAPI-додаток з Ormar-моделями із зовнішніми ключами

Виконала: Іващук Евеліна, група 444Б

## Файли проекту

| Файл | Призначення |
|---|---|
| `database.py` | підключення до бази даних (за замовчуванням SQLite, файл `library.db`) |
| `models.py` | Ormar-моделі: `Human`, `Dog`, `Author`, `Book`, `Review` |
| `schemas.py` | схеми Pydantic для перевірки вхідних даних |
| `main.py` | додаток FastAPI та ендпоїнти `/human/` і `/dog/` (хід роботи) |
| `library.py` | ендпоїнти `/authors/`, `/books/`, `/reviews/` (самостійне завдання) |
| `test_api.py` | тести API |
| `requirements.txt` | потрібні бібліотеки |

## Зв'язки між моделями

- `Dog.owner` → `Human`: у людини може бути багато собак; людину, яка має собак, видалити не можна;
- `Book.author` → `Author`: в автора може бути багато книг; автора, який має книги, видалити не можна;
- `Review.book` → `Book`: про книгу може бути багато відгуків; разом з книгою видаляються її відгуки.

## Встановлення

Відкрийте термінал у папці `Lab14` і виконайте:

```
py -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## Запуск

```
.venv\Scripts\python.exe -m uvicorn main:app
```

Потім відкрийте у браузері http://127.0.0.1:8000/docs — це сторінка Swagger для тестування API.
Зупинити додаток: `Ctrl+C`.

## Тести

```
.venv\Scripts\python.exe test_api.py
```

Тести працюють з окремою тимчасовою базою даних і не змінюють файл `library.db`.
