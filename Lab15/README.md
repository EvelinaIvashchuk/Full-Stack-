# Лабораторна робота №15. Веб-додаток з моделлю машинного навчання

Виконала: Іващук Евеліна, група 444Б

Варіант 5 — Text Emotion Recognition: веб-додаток визначає емоцію англомовного тексту (sad або happy).

## Файли проекту

| Файл | Призначення |
|---|---|
| `train.csv` | датасет з Kaggle (254 539 текстів; стовпці `text` і `emotion`: 0 — sad, 1 — happy) |
| `preprocess.py` | функція очищення тексту, спільна для навчання і веб-додатку |
| `train_model.py` | навчання моделі та збереження її у файли |
| `model.pkl`, `vectorizer.pkl` | навчена модель і векторизатор (створює `train_model.py`) |
| `app.py` | веб-додаток на Flask |
| `templates/index.html` | сторінка з формою |
| `requirements.txt` | потрібні бібліотеки |

Датасет: https://www.kaggle.com/datasets/shreejitcheela/text-emotion-recognition (файл `train.csv`, ліцензія CC0).

## Запуск

У папці `Lab15` вже є віртуальне середовище `.venv` з бібліотеками та навчена модель.

Запустити веб-додаток:

```
.venv\Scripts\python.exe app.py
```

Потім відкрийте у браузері http://127.0.0.1:5000, введіть текст англійською і натисніть **Check**.

Навчити модель заново (триває близько 10 секунд):

```
.venv\Scripts\python.exe train_model.py
```

Якщо папки `.venv` немає, створіть її:

```
py -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## Обмеження моделі

Модель орієнтується на окремі слова та пари слів, тому погано розуміє заперечення: текст «I am not happy at all» вона відносить до класу happy, хоча й з низькою впевненістю (51%).
